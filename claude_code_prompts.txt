PROJECT CONTEXT TO KEEP WITH THE PROMPTS
A civic education nonprofit provides free mathematics Olympiad training to high school students. This hackathon component drafts teacher-reviewed feedback from PDFs; it is not the whole nonprofit LMS. Assume the demo inputs are synthetic student submissions, with a separately selected optional teacher-approved reference folder. Confirm that assumption before building. There are no automatic grades, autonomous student messages, real minors' data, or claims of mathematical proof verification.

Candidate architecture, subject to repository audit and approval: Python, FastAPI/Pydantic, minimal HTML review screen, SQLite-backed jobs, one worker, local text-PDF extraction adapter, one real hosted model adapter and a deterministic fake. A second real provider and Docling are optional. No GPU, model-weight download or multiagent framework is assumed. Agent-agnostic means the same versioned JSON contract is usable through HTTP and a thin CLI, regardless of provider or orchestration framework.

The public demo uses only fixed synthetic fixtures and approved results, with no anonymous arbitrary uploads. Review administration is authenticated or local-only. The proposed deployment is one DigitalOcean CPU Droplet with Docker Compose, a persistent named volume and an HTTPS reverse proxy at a .tech hostname. Domain, repository, credentials, credits and spending limit are not known. Deployment remains a plan.

Published event schedule: 28 October 2026, building at 13:00 and demos at 17:00 Mexico City time. Pre-event code permission and the precise submission cutoff are not confirmed. Freeze features at 16:00, stop deployment troubleshooting by 16:15, and reserve at least 45 minutes for submission and rehearsal. Move these cutoffs earlier if organizer rules require it. Do not infer the actual team size from the advertised team format.
